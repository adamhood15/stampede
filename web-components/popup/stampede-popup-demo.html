Demo host page

Stands in for an arbitrary typhoontexas.com page. The popup fires on a timer (default 6s) and is otherwise fully self-contained — nothing else on this page had to be built for it to work.

Uses window.STAMPEDE_POPUP_CONFIG.delayMs = 2000 below so it fires quickly for testing without feeling instant; production embeds should leave the default (6000ms) or set their own.
